# Poppins assets

Poppins Regular (400), Medium (500) and SemiBold (600) are bundled locally so the application does not fetch typography at runtime.

Source: [Google Fonts Poppins repository](https://github.com/google/fonts/tree/main/ofl/poppins), retrieved 27 November 2026. The original filenames and font binaries are retained. Redistribution terms and copyright notices are in [OFL.txt](OFL.txt).
